# 🐍 Python Mini Projects

A collection of Python mini projects created to practice programming concepts, problem-solving, and real-world applications.

## 📌 About

This repository contains small Python projects built to improve programming skills. The projects cover basic to intermediate topics, including mathematics, games, automation, APIs, and file handling.

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/arshiasadri/python-mini-projects.git
```

Run any project:

```bash
python project_name.py
```
